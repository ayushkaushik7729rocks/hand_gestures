# Gesture Controlled Drone

A computer vision based system that controls a drone using hand gestures.

## Features
- Real-time hand detection
- Gesture based movement control
- OpenCV powered vision system

## Technologies Used
- Python
- OpenCV
- MediaPipe

## How to Run
1. Clone the repository
2. Install requirements
3. Run main.py
